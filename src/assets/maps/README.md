# Malaysia state map

`malaysia-states.json` contains simplified SVG paths derived from the Department
of Statistics Malaysia (DOSM) state boundaries:
https://github.com/dosm-malaysia/data-open/blob/main/datasets/geodata/administrative_1_state.geojson

Retrieved 10 October 2026. Used under the DOSM Open Data Licence; the original
licence is included in `LICENSE.dosm.md`. This use does not imply DOSM endorsement.

Coordinates are simplified and projected into separate Peninsular and East
Malaysia panels for an educational interface, not navigation. Small federal
territories also have enlarged, labelled controls for selection.

University entries come from the active Nexus catalogue, not the boundary dataset.
