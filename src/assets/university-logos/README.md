# University logos

Optimised copies of the logos in the project's `UNI LOGO` folder (near-white backgrounds made
transparent, cropped and resized to at most 460px wide, saved as `.webp`). They are used by
`src/components/landing/universityLogos.js` for the landing-page strip, the map pins and the
university list.

To add one, drop a `.webp` file here and add an entry (with its campus position on the map) to
`universityLogos.js`. Only add logos you have permission to use, and record the source here.
